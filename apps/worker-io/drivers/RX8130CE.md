# RX8130CE clock setting

`Rx8130ce` polls the RTC at I2C address `0x32`. Polls read `0x10..0x1e` in one transaction and never modify the chip. `currentValid` describes the latest poll; it becomes false on invalid fields, VLF, STOP, TEST or a failed read. `latest` retains the last valid sample for display history and does not establish current validity.

`requestSetTime({ year, month, day, hour, minute, second })` accepts one request. Fields must be integers, the year must be **2000–2099**, and the date must exist in the Gregorian calendar. Hours use 0–23; minutes and seconds use 0–59. The driver computes the one-hot weekday with Sunday at bit 0. Accepted input is copied. A false return means invalid input, another setting in progress, or a closed resource. Calling this API does not itself change the RTC; the driver's task executes the request from the next turn, and `settled()` resolves with the final status.

`setting` stays true until completion or failed recovery. `setStatus` progresses through `queued`, `reading`, `writing`, `verifying` and, on uncertain outcomes, `recovering`. Only the final verified result sets `succeeded` and `lastSetTime`. `setError` describes a failed request; an accepted request clears it. The existing `error` field retains the most recent transport error. The UI sends a setting request only after the user confirms its displayed date and time.

The sequence follows [Epson RX8130CE application manual ETM50E-10](https://download.epsondevice.com/td/pdf/app/RX8130CE_en.pdf), sections 13.2, 14.1, 14.5 and 18.5:

1. Read CTRL0 (`0x1e`). Preserve its six unrelated bits. TEST must be zero on every write. RX8130CE has a fixed 24-hour BCD hour register; there is no 12/24-hour mode bit.
2. Submit three writes as **one I2C transaction**: set STOP, write seven contiguous clock/calendar bytes at `0x10`, then clear STOP. The script uses seven of the controller's eight command slots. The normal path does not retain STOP across worker turns.
3. Read all fifteen bytes and compare the calendar, weekday and CTRL0 with the requested value. Readback permits forward clock advancement within the measured elapsed time, rounded up to a second. VLF is allowed at this intermediate check.
4. Write `0xbd` to FLAG (`0x1d`). This clears VLF. Other write-zero-to-clear flags receive one, preserving events that arrived since the earlier read. Reserved bit 6 receives zero; VBFF is read-only. Battery charging, backup switching, alarms and timer configuration are not changed.
5. Read all fifteen bytes again. The final time must match and VLF, STOP and TEST must be clear. A successful bus transfer alone is not a successful setting.

An accepted setting has a two-second deadline. Queue rejection retries after one millisecond; an overdue accepted request is cancelled and its outcome is observed. A partial write, timeout or cancellation may have left STOP set. The driver then makes at most three attempts to restore CTRL0 and read it back. Each recovery uses eight hardware command slots and the driver's 20 ms transaction timeout. Recovery never turns an uncertain clock write into a successful setting, and the calendar write is never retried after an unknown outcome.

`close()` during a potentially stopped write runs this recovery before closing the resource; `setting` becomes false when the task ends. **Power loss or forced worker shutdown can interrupt the native transaction or recovery and leave STOP set.** A recovery failure reports that possibility. A later confirmed setting can restart the clock. This clock-setting API does not perform Epson's complete power-on initialization or configure battery charging; board firmware remains responsible for those functions. The worker has exclusive ownership of address `0x32` while this driver is open.

Host tests drive the driver through the SDK scheduler against an I2C register model with partial transactions, write-zero-to-clear flags, queue rejection, cancellation and the eight-command limit. Run `./tools/test-worker-io.sh`. Hardware verification must also check the displayed readback after applying a time.
